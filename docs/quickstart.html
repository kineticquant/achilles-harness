Quickstart

Get the desktop app running, configure a model, and scan a workspace.

Run from source

From the repo root (Git Bash on Windows):

./start-desktop.sh

Or double-click start-desktop.cmd. First run compiles the CLI (several minutes). Later runs reuse that binary unless you pass --rebuild.

You need Rust, a C/C++ toolchain (MSVC Build Tools on Windows), Node.js + pnpm, and Git. Hermit can provide Node/pnpm if you use it:

source ./bin/activate-hermit
cargo build --release -p goose-cli --bin goose

Onboarding: pick a model

  1. When the window opens, configure a provider if asked (API key, or a local path such as Arrav).
  2. Arrav is optional. Any provider Achilles lists will run the agent.
  3. You can change provider and model later in Settings.

First scan

  1. Open Findings (Scan in the sidebar).
  2. Choose a workspace (your repo). For a safe demo, use examples/achilles-scan-fixture.
  3. Pick a depth: fast (engines only), investigate, or deep (engines, then an agent loop on ledger ids only).
  4. Run the scan and triage cards. Repair is not an Achilles job — copy a brief or use Tools / MCP and patch in your editor.

Installers

Technical preview. Desktop installers from GitHub Releases are unsigned. Windows SmartScreen and macOS Gatekeeper warnings are expected. Prefer building from source if you do not want to bypass OS prompts.

CLI

The interactive product is desktop Findings. The CLI binary is still named goose:

goose appsec scan --path examples/achilles-scan-fixture
goose appsec query --path examples/achilles-scan-fixture

quick (default) walks the tree. --mode diff limits secrets/SAST/surfaces to git-changed files; SCA still reads lockfiles.
