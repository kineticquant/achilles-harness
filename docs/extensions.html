Extensions

Extensions are tools the agent can call: built-in platform extensions, and MCP servers you add.

Built in

Open Extensions in the sidebar or Settings. Toggle what you want for the session. Developer is required for file tools and for .goosehints. AppSec is what Findings uses to scan and query the local ledger.

Some unused builtins (tutorial, computer controller, auto visualiser) are hidden and are not offered in Settings.

Add a custom extension

  1. Click Add custom extension.
  2. Choose stdio (a local command) or SSE/HTTP (a URL).
  3. Fill name, command or endpoint, and any env vars.
  4. Save, then enable it. Start a new chat if tools do not appear.

There is no separate Achilles extension marketplace yet. Use MCP servers you already trust, or ship them with a recipe.

MCP from Findings

Findings can expose Achilles as an MCP server to Cursor, Claude Code, Codex, and OpenCode so those apps pull findings and mark them fixed. Use the connect snippet on the Findings rail — they apply the patch; you rescan here.
