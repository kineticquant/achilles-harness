Project hints (.goosehints)

A plain-text file the agent reads as extra project context. The filename is .goosehints.

Enable the Developer extension. Restart the session after you save hints so they load into the prompt.

Where to put it

  • This workspace — Settings → Chat → Project Hints, or a .goosehints file at the project root (and optionally in nested dirs).
  • All sessions — ~/.config/goose/.goosehints (on Windows, %USERPROFILE%\.config\goose\.goosehints).

Local hints win if they conflict with global ones. Nested directories load as the agent walks the tree. Keep the file short; it is added to the system prompt and uses tokens.

What to write

Direct sentences: build commands, “do not touch generated/”, how tests run, secrets that must never be committed. Repeat-prompt material belongs here.

# Example
Use pnpm, not npm.
Do not edit ui/desktop/src/bin.
Findings live in achilles.db; do not invent extra issues.
