Recipes

A recipe starts a whole session with tools, parameters, and a prompt already set. Skills teach mid-chat; recipes are the playbook you run on demand or on a timer.

Shipped recipes

YAML under recipes/ is compiled into the app. On launch they appear in the Recipe Library (not deletable; editing saves a personal copy).

  • scan-recap — scan a workspace, then recap open findings
  • sca-hygiene-report — known-vulnerable deps plus pinning / lockfile hygiene
  • security-review — high-confidence review of a PR, branch, or git diff

Recipes call appsec_scan / appsec_query / appsec_intel. Engines still write achilles.db. Do not treat the recipe folder as a second scanner.

Desktop

Sidebar → Recipes → Run. To automate: open the recipe and Schedule, or Scheduler → Create Schedule and pick it from the library. The scheduler only fires recipes; it is not a scan queue.

CLI

goose run --recipe scan-recap --params workspace=/path/to/repo
goose run --recipe recipes/security-review.yaml --params workspace=/path/to/repo --params pr=123

Pass workspace on schedules so the job does not scan the server’s current directory.

More detail: recipes/README.md.
