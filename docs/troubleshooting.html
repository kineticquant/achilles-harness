Troubleshooting

Preview software. Check these before filing an issue.

Unsigned desktop builds

GitHub Release installers are unsigned. Windows SmartScreen and macOS Gatekeeper will warn. That is expected. Build from source with ./start-desktop.sh if you do not want to bypass those prompts.

App will not start

  • Confirm the CLI built: cargo build --release -p goose-cli --bin goose
  • On Windows, use Git Bash for Hermit / start-desktop.sh, and MSVC Build Tools for Rust
  • pnpm version must match ui/desktop/package.json engines

Diagnostics

In an active chat, use the diagnostics control in the toolbar. Download the JSON bundle (diagnostics_{session_id}.json). It includes OS, app version, enabled extensions, provider/model, and recent logs. Attach that file when you report a bug.

CLI:

goose session diagnostics --session-id <session_id>

Keychain / secrets

If goose configure cannot store API keys, your OS keyring may be unavailable. Set provider keys as environment variables instead (for example OPENAI_API_KEY, ANTHROPIC_API_KEY) and run configure again, or use GOOSE_PATH_ROOT to isolate config for testing.

Report a bug

Settings → App → Help & feedback, or the diagnostics modal → file on GitHub. Issues: kineticquant/achilles-harness. Include OS, Achilles version, extensions, provider/model, and the diagnostics JSON.
