Achilles guidance

Local agent harness: desktop app, CLI, and AppSec Findings. Arrav is the optional local model — any configured provider works.

  • Quickstart — install from source, pick a model, run a scan
  • Extensions — built-in tools, MCP, adding your own
  • Project hints — .goosehints for extra project context
  • Recipes — packaged scans and recaps
  • Troubleshooting — unsigned builds, diagnostics, filing issues

Source: github.com/kineticquant/achilles-harness. Product site achilles.sh is not the docs host yet — these files are the in-app Help targets until then.
