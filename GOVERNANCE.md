# Achilles governance

This repository is **Achilles** (the harness) and **Arrav** (the optional local model).

## Where work happens

- Issues and pull requests: [kineticquant/achilles-harness](https://github.com/kineticquant/achilles-harness)
- Product docs: [`docs/`](docs/README.md)
- License: Apache 2.0 — [LICENSING.md](LICENSING.md)

Achilles was built on [goose](https://github.com/aaif-goose/goose).

## Contributions

Open an issue or PR on this repo. Keep Apache notices intact. Do not mass-rename internal `goose` crate or CLI identifiers unless that is an explicit, scoped change.

Tie-breakers and merge rights sit with the people who operate `origin` on this repository.
