Achilles — Dev setup

Quick guide for Python developers. Rust’s equivalent of requirements.txt / pip install, plus what must be installed before this harness builds on Windows.

Python → Rust cheat sheet

Python Rust
requirements.txt / pyproject.toml Cargo.toml (declared dependencies)
Lockfile (poetry.lock, etc.) Cargo.lock (pinned versions — already in this repo)
pip install -r requirements.txt cargo build (downloads + compiles crates into target/)
venv Not really needed — Cargo manages deps per project
pip list cargo tree (after the toolchain is installed)

There is also a Node / UI side (ui/pnpm-lock.yaml) — a second package manager for the Electron desktop app.

Are dependencies installed?

Having Cargo.lock in the repo is not the same as having crates downloaded and compiled on your machine. Check with: 

rustc --version
cargo --version
node --version
pnpm --version

Typical Windows status before first setup:

Thing Meaning
Rust (rustc / cargo / rustup) Must install
MSVC Build Tools (C++) Must install on Windows
Node.js Needed for desktop UI
pnpm Install if missing (npm install -g pnpm)
target/ folder Appears after first successful cargo build
node_modules under ui/ Appears after pnpm install

Minimal setup (once)

  1. Install Rust from https://rustup.rs/. Run the installer, then open a new terminal.
  2. Install Visual Studio Build Tools (download). Select the Desktop development with C++ workload. Rust on Windows needs this to link native code.
  3. Install pnpm (for the UI): 
    npm install -g pnpm
  4. Fetch & build Rust deps from the repo root: 
    cargo build
    First run downloads a lot and can take a long time — that is normal.
  5. UI deps (when you work on the desktop app): 
    cd ui\desktop
pnpm install
After cargo build succeeds without errors, your Rust side is set up. Use cargo build --release -p goose-cli --bin goose for a release CLI binary, and see the root README.md for running the UI.
